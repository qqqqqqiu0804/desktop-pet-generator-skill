# 桌面宠物 (Desktop Pet)

基于 PyQt5 的 Windows 桌面宠物程序，支持透明背景、自由行走、鼠标拖拽、系统托盘。

## 功能

- ✅ 无边框透明窗口，始终置顶
- ✅ 桌面自由行走，边缘自动反弹
- ✅ 鼠标左键拖拽移动
- ✅ 双击触发跳跃动画
- ✅ 待机呼吸效果
- ✅ 系统托盘右键菜单
- ✅ 多种形象切换
- ✅ 大小调节（鼠标滚轮 / 托盘菜单 / 右键菜单）
- ✅ AI 抠图智能去背景
- ✅ 一键打包 EXE

## 快速开始

### 运行源码
```bash
pip install -r requirements.txt
python process_images.py --ai    # 去除背景（AI模式效果最好）
python main.py
```

### 打包成 EXE
双击 `build.bat`，生成的文件位于 `dist/DesktopCat.exe`

## 图片准备

将宠物图片放入 `assets/` 目录：

| 文件名 | 说明 | 必需 |
|--------|------|------|
| cat_stand.jpg | 站立形象 | ✅ |
| cat_sit.jpg | 坐姿形象 | ⭕ |
| cat_lie.jpg | 趴卧形象 | ⭕ |

只有一张图也能用，其他姿态会自动复用站立图。

## 操作说明

| 操作 | 效果 |
|------|------|
| 左键拖动 | 移动宠物 |
| 双击左键 | 跳跃 |
| 鼠标滚轮 | 调节大小（步长5%） |
| 右键宠物 | 快捷菜单（含大小调节） |
| 右键托盘图标 | 完整功能菜单（含大小调节） |
| 双击托盘 | 显示/隐藏 |

## 大小调节

支持三种调节方式：

| 方式 | 操作 | 步长 |
|------|------|------|
| 鼠标滚轮 | 在宠物上滚动滚轮 | 5% |
| 托盘菜单 | 右键托盘 → 调整大小 | 预设6档 + ±10%微调 |
| 宠物右键菜单 | 右键宠物 → 调整大小 | 同上 |

**预设档位**：
- 迷你 50% / 小 70% / 中 100% / 大 130% / 特大 160% / 巨无霸 200%

**缩放范围**：30% ~ 300%

**特性**：
- 含屏幕边界保护，放大后不会超出屏幕
- 程序重启后记住上次设置的大小

## AI 抠图

使用 `rembg` 库进行智能背景去除，支持两层处理模式：

```bash
# 安装依赖
pip install rembg onnxruntime

# 处理图片（AI模式 + 后处理优化）
python process_images.py --ai

# 处理图片（基础亮度阈值模式）
python process_images.py --basic
```

### AI 模式优化

AI 模式内置 **Alpha 通道后处理**，效果更干净：

| 处理步骤 | 说明 |
|---------|------|
| Sigmoid 阈值锐化 | 将半透明像素推向 0 或 255，消除灰色残留 |
| 二次清理 | alpha < 30 直接归零，alpha > 200 直接拉满 |
| 边缘羽化 | 高斯模糊消除锯齿，让边缘过渡更自然 |

处理完成后会输出统计信息：
```
半透明像素: 12345 → 2345 (减少 81.0%)
```

### 适用场景

- **AI 模式**：复杂背景、渐变背景、有阴影的图片
- **基础模式**：纯色背景（白色、绿色等）

## 自定义参数

编辑 `main.py` 调整：
- `walk_speed = 2` — 行走速度
- 跳跃初速度、重力等动画参数
