# 桌面宠物 (Desktop Pet)

基于 PyQt5 的 Windows 桌面宠物程序，支持透明背景、自由行走、鼠标拖拽、系统托盘。

## 功能

- ✅ 无边框透明窗口，始终置顶
- ✅ 桌面自由行走，边缘自动反弹
- ✅ 鼠标左键拖拽移动
- ✅ 双击触发跳跃动画
- ✅ 待机呼吸效果
- ✅ 系统托盘右键菜单
- ✅ 多种形象切换
- ✅ 一键打包 EXE

## 快速开始

### 运行源码
```bash
pip install -r requirements.txt
python process_images.py --ai    # 去除背景（AI模式效果最好）
python main.py
```

### 打包成 EXE
双击 `build.bat`，生成的文件位于 `dist/DesktopPet.exe`

## 图片准备

将宠物图片放入 `assets/` 目录：

| 文件名 | 说明 | 必需 |
|--------|------|------|
| pet_stand.jpg | 站立形象 | ✅ |
| pet_sit.jpg | 坐姿形象 | ⭕ |
| pet_lie.jpg | 趴卧形象 | ⭕ |

只有一张图也能用，其他姿态会自动复用站立图。

## 操作说明

| 操作 | 效果 |
|------|------|
| 左键拖动 | 移动宠物 |
| 双击左键 | 跳跃 |
| 右键宠物 | 快捷菜单 |
| 右键托盘图标 | 完整功能菜单 |
| 双击托盘 | 显示/隐藏 |

## 自定义参数

编辑 `main.py` 调整：
- `pet_size = QSize(120, 140)` — 显示尺寸
- `walk_speed = 2` — 行走速度
- 跳跃初速度、重力等动画参数

## 环境要求

- Windows 7 / 10 / 11
- Python 3.8 ~ 3.11
